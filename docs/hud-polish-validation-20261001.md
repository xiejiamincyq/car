# N7 HUD与金币反馈验证

## 本轮实现

- 使用深蓝70%半透明面板、青色速度仪表、绿色燃油和金色得分。全部布局/仪表/粒子由代码绘制，没有新增或修改美术素材。
- 左下：大速度表（数字、指针、刻度、km/h）和小燃油表（指针、百分比）。左上：赛段、连击、比赛/暂停状态；下方完整度/燃油/超载长条。顶部中央：当前距离/实际关卡终点和长进度条。右上：分层得分数字和金币计数。
- 移除比赛HUD中的WS速度、双击W超载、AD转向、暂停/静音键位与种子提示。只移除显示，驾驶绑定与帮助界面保留。原“联机”位置实际为“连击/COMBO”，没有新增联网功能。
- 完整度在70%与30%用金色/红色区分，保留阈值刻线。燃油低于30%/15%仍有文字警告，低油/危急色不再与旧绿字叠乘导致变暗。距离使用当前RunState终点，避免其他赛道提前显示满条。
- 金币由上滑电子提示音改成44.1kHz、0.22秒的稳定双音铃声，软起音/衰减/收尾；最多3个铃声尾音重叠，连续拾取不总是截断上一声。原有连击轻微升调、音量总线/静音/暂停管理保留。
- 拾取特效为金色菱形碎光、短拖尾、柔和扩散环和上浮“+1”；移到车辆渲染之后，不被车身遮挡。最多12个短寿命特效，单次最多10粒；减少闪烁时保留克制扩散环/浮字，不发射碎光。

## 验证

- 先用HUD布局失败测试证明旧布局不符合要求，补金币反馈失败测试，再实现。更新旧“英文HUD应显示按键”的断言以符合新需求，保留菜单本地化和真实暂停状态检查。
- `scripts/tests/run_tests.ps1`：83项全量通过，日志 `tmp/hud-polish-final-tests-20261001.log`。原有退出ObjectDB/资源清理警告仍存在，不宣称零警告。
- 新专项覆盖波形长度/峰值/首尾无点击/相邻采样跳变、粒子边界和有界复音；布局覆盖1280×720、1920×1080、角落位置、长条同步、当前关卡进度和暂停状态。
- 实际主场景12张截图逐图检查：中英文×正常/低油重损大数字×720p/1080p（8张）；另外三关720p和货运港高对比（4张）。示例数值为人为注入，不证明真实驾驶成绩。
- 结果图 `docs/previews/hud/instruments-720.png` 和 `warning-1080.png`；其余本地截图及日志为 `tmp/hud-final-*`。
- 控件不接收鼠标/键盘焦点，布局仅在尺寸变化时重排；面板样式缓存，未引入每帧Tween或新外部依赖。没有独立性能基准，也没有替代人类完成物理听感验收。

## 人工检查点

启动货运港、pulse_gt、标准难度、种子611的无存档写入试玩。请确认边角仪表易读且不抢道路注意力；低油/受损提示清晰；连续金币拾取的音量、音色和碎光强度舒适。键位仍为原来的W/S、A/D、双击W、Space，但不在比赛HUD占位置。

本轮不调整驾驶、油耗、金币生成、碰撞/完整度或评分数值。人工确认后回到N3.2/N3.3综合平衡；不打包、不发布。
