# Neon Coast Rush MVP 定义

## 一句话定位

面向 PC 键盘试玩的 2D 纵向卷轴街机赛车：玩家在不断加速、愈发拥挤的三车道公路中躲避车辆、完成超车、收集燃油，以距离和分数挑战更长的单局成绩。

## 参考与边界

本项目参考《Road Fighter》可观察到的**玩法原则**：自上而下的高速行驶、道路纵向滚动、车流穿插、燃油压力、关卡/难度递进与短局重玩价值。

不复制《Road Fighter》的受版权保护表达：不使用其名称、角色、车辆外形、美术、音乐、音效、关卡地图、UI、文案、精确数值或逐帧/逐关布局。项目使用原创名称、原创车辆与道路主题、原创资源，并通过自己设计的交通行为和难度曲线建立相似但独立的街机体验。

## 核心体验目标

- **30 秒内上手：** 仅靠方向键/WASD 就知道如何控制与避险。
- **每 5–10 秒一次决策：** 是跟车减速、横向变道，还是冒险从缝隙超车。
- **失败可归因：** 撞车、燃油耗尽和道路边界均有明确反馈，不出现无预警必死局。
- **一局 2–4 分钟：** 适合反复挑战，并能让熟练玩家持续提升分数。

## 首版核心规则

| 项目 | 首版规则 |
|---|---|
| 视角 | 纵向卷轴、玩家车位于屏幕下方约 70% 的位置 |
| 操作 | 左右：转向；上/W：加速；下/S：减速；Esc：暂停；R：重开 |
| 道路 | 三车道、有限左右边界；不做真实赛道物理 |
| 交通 | 慢速直行车、规律变道车、高速追越车；先做到“看得懂”，再增加随机性 |
| 碰撞 | 撞车减速、短暂无敌、视觉震动与音效；连续碰撞累计风险而非立即结束 |
| 资源压力 | 燃油随时间/速度消耗；拾取燃油桶补充；燃油归零结束本局 |
| 成绩 | 距离为主、超车/险些擦过为加分项；首版无需线上排行榜 |
| 难度 | 通过车流密度、车速差、变道频率逐段提高，不靠突然生成车辆 |

## MVP 范围

- 一条可无限延伸的原创公路主题（例如夜间海岸公路）。
- 可操控玩家车、三类交通车辆、燃油补给、碰撞和完整的开始—暂停—结束—重开循环。
- 分数、距离、燃油 HUD，最小化设置（音量、按键提示）。
- 原创的几何占位资源；核心手感确认后再替换为原创像素/扁平风格资源。
- 首个发布目标为 Windows；Web 导出仅在 MVP 已稳定后评估。

## 首版明确不做

- 多人、联网、排行榜、账号、存档云同步。
- 真实漂移、轮胎抓地、车辆改装、赛事生涯。
- 多赛道、Boss、复杂剧情、商城。
- 手机触屏、手柄适配、完整无障碍配置（作为后续版本候选）。

## 成功标准

- 3 名首次试玩者无需口头教学即可完成一次有效行驶。
- 首次试玩者平均能坚持至少 30 秒；熟练试玩者可稳定达到 2 分钟以上。
- 十次随机开局中不出现前 15 秒无解碰撞或无燃油可取的局面。
- 以键盘从启动到重开稳定运行，无崩溃、无明显掉帧。
