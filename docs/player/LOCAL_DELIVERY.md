# Neon Coast Rush：本机交付说明

四条赛道、六辆赛车、三种难度；支持中文/英文和PC键盘。此目录是用户试玩接受后的本机交付，不是公开发行。

## 开始游戏

双击`game/NeonCoastRush.exe`即可运行，无需Godot编辑器。不要单独移动EXE，保留同目录PCK。也可完整解压`NeonCoastRush-Windows-local.zip`，再启动其中的EXE。

操作：W/↑加速，S/↓制动，A/D或左右箭头转向；双击前进键超载；Space暂停/继续；R重开；F11全屏。选车后按确认按钮开局。详细操作及四存档说明见`game/README.md`。

比赛结束自动保存，手动保存仍保留。存档位于`%APPDATA%\Godot\app_userdata\Neon Coast Rush`，不随游戏ZIP携带。

用户已确认“试玩通过，跳过进行下一步”。因此不再要求剩余驾驶补证。四关1080p逐帧性能、30分钟有效驾驶、20次重开/返回趋势及剩余正常新档/旧档完整胜负流程，记为用户授权跳过，不是技术测试PASS；不保证已经达到60FPS或没有长期内存增长。

## 安全回退与反馈

当前进度格式v7。遇到异常先关闭游戏，备份整个存档目录，再切换游戏文件；不要让旧版本直接覆盖v7存档。保留本交付目录和原候选目录，恢复游戏文件时使用成套EXE/PCK。回退程序不等于存档降级；没有匹配的旧档副本时不要强行降级进度。
