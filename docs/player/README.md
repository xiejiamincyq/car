# Neon Coast Rush — 0.4.0-rc.5

Windows x64公开RC预发布版，保留0.4.0-rc.5版本号，不冒称1.0稳定版。四条赛道、六种车型、三种难度；支持中文和英文。验证范围见RELEASE_STATUS.md。

在线阅读：[发布状态与验证范围](../releases/v0.4.0-rc.5/RELEASE_STATUS.md) · [常见问题与反馈](SUPPORT.md)。包内同名说明仍随下载保留。

## 开始游戏

完整解压后双击`NeonCoastRush.exe`，保留同目录的`NeonCoastRush.pck`。无需安装Godot编辑器。先选择赛道，再选择车辆查看属性，按“确认选择并开始比赛”开局；锁定车型需要完成对应解锁条件。

| 按键 / Key | 操作 / Action |
| --- | --- |
| W / ↑、S / ↓ | 加速、制动 / Accelerate, brake |
| A / ←、D / → | 转向 / Steer |
| 双击前进键 / Double-tap forward | 超载；两次按下之间先松开全部前进键 |
| Space | 比赛暂停/继续；菜单确认 / Pause, resume, confirm |
| Enter、Tab / Shift+Tab | 菜单确认、切换焦点 / Confirm, move focus |
| R、Esc | 重开确认、返回/取消 / Restart, back/cancel |
| M、- / +、F11 | 静音、音量、全屏 / Mute, volume, fullscreen |

收集金币提高过程评分；油罐补充燃油，工具箱修复完整度。燃油耗尽或完整度低于20%会失败；困难模式通常需要沿路补油。完整度降低会影响车速和转向。超载最多额外100 km/h，持续4.5秒，逐步消耗15%油箱容量；不要把按住前进键的键盘重复当成双击。

## 赛道与评分

金币满分目标为本局实际生成金币的90%；用时基准按最慢车型普通极速巡航计算。未完赛也会根据实际进度和过程表现结算。

简单模式车流少、补给密集、变道预警更长。标准模式适中。困难模式开局就可能遇到变道车，普通车流更密、变道更频繁、预警更短，同时补给更少、油耗和碰撞代价更高；玩家车辆的基本操控不被人为削弱。

红色快车出场前会显示至少1秒的整道红色预警和向上箭头。通道安全后，它固定以450 km/h驶过，不跟随玩家加减速、不临时变道；玩家超载超过450时可以跑赢它。普通车会在安全时让道，抵近阶段暂缓新交通和新施工，通过后恢复车流；现有施工和道具不会凭空消失。

左侧小地图显示检查点、终点、当前位置和下一目标距离。道路上的青色棋盘标线为检查点，金色为终点，不是障碍物。施工锥桶可以撞开，但会损伤车辆。

声音设置可分别调整音乐与音效；设置中也可切换语言、高对比、减少闪烁及屏幕震动。没声音时先检查游戏静音、三路音量与Windows当前输出设备。

## 存档与反馈

标题界面的“存档管理”提供四个独立栏位，分别保存生涯、成绩、解锁和设置；重启记住当前栏位。加载空位开始新进度，比赛中只能保存当前档，不能切档。复制会保留源档，覆盖目标与删除均需确认；删除或被覆盖的原文件保留在 `save_slots/recovery` 目录。删除当前档后需重新加载一个栏位才恢复保存。首次升级只把旧 `save.cfg` 复制到1号位，保留原件；之后删空存档不会再次导入。

通关或失败结算后自动保存，标题存档管理及暂停菜单仍可手动保存。“生涯”按时间倒序分页查看逐局得分，结算中单独显示本局得分；百分制评级另计。旧存档保留累计生涯与最高成绩，逐局历史从本次升级后开始记录，不补造旧对局。

游戏报告保存失败时不要假定已保存，可返回标题手动重试。用户目录为Windows默认Godot位置`%APPDATA%\Godot\app_userdata\Neon Coast Rush`，与解压目录无关。本次进度格式为v7，旧候选不支持新增历史；备份该目录后再迁移或回退，不删除唯一有效的`save.cfg`或`save.cfg.bak`，不要用旧程序覆盖新档。

程序未签名，Windows可能提示安全警告，不要因此关闭系统安全功能。验证范围和已跳过项目见`RELEASE_STATUS.md`；发现异常请记录版本、赛道、车型、难度、操作步骤和截图，不需要提供私人存档。素材来源见`ASSET_NOTICES.md`，引擎声明见两份`GODOT_*.txt`。项目所有者已批准本包通过GitHub Release公开发布。
