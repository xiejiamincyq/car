# 常见问题、已知限制与反馈

适用版本：0.4.0-rc.5，Windows x64便携版，未签名。下载入口：[GitHub Release](https://github.com/xiejiamincyq/car/releases/tag/v0.4.0-rc.5)。

## 下载后怎么运行？

下载NeonCoastRush-0.4.0-rc.5-Windows-x64.zip，而不是GitHub自动生成的Source code源码包。完整解压后进入版本文件夹运行NeonCoastRush.exe；EXE和同目录PCK必须成套保留。玩家不需要Godot编辑器、Python或Node.js。

## Windows提示未知发布者或阻止运行

此EXE没有代码签名，可能遇到Windows信誉或组织策略拦截。只从上述发布页下载，并用SHA256SUMS.txt核对；SHA校验用于比对文件是否一致，不是签名、无毒保证或安全审计。不要为了运行游戏关闭Defender、SmartScreen或组织安全策略；仍不能运行时保留具体提示并反馈。

PowerShell校验示例：

```powershell
Get-FileHash .\NeonCoastRush-0.4.0-rc.5-Windows-x64.zip -Algorithm SHA256
```

## 存档、备份与卸载

存档在`%APPDATA%\Godot\app_userdata\Neon Coast Rush`，不是解压目录。四栏位分别保存生涯、解锁和设置；结算自动保存，仍可手动保存。复制、覆盖、删除和恢复详情见[玩家指南](README.md)。

升级/回退前先退出游戏，将整个上述存档目录复制到自己的备份位置。当前是v7格式，不保证旧程序可读取；不要用旧程序覆盖新档或仅有的有效备份。

便携版无需安装服务或驱动。退出游戏后移除解压目录即可卸载程序，存档默认保留。若确实不再需要存档，应先核对并自行备份上述准确目录，再单独移除；不要清理整个Godot或AppData目录。

## 没声音、显示异常或无法启动

- 音乐：检查游戏静音、主音量/音乐/音效三路设置及Windows当前输出设备。
- 资源错误：确认不是从压缩包内直接运行，EXE/PCK没有拆散或混用不同版本。
- 画面：可尝试游戏内窗口模式/全屏切换。当前只在一台Windows x64电脑验证，其他硬件/驱动兼容性未保证。
- 仍有问题：不要反复删除存档或降低系统安全设置，按下方格式反馈。

## 已知验证边界

用户已接受本机试玩；四关1080p逐帧性能、30分钟有效驾驶、20次重开/返回趋势和剩余正常新旧档完整胜负流程补证由用户授权跳过，并未通过技术验证。不承诺固定帧率或长期零内存增长。历史自动测试退出时存在ObjectDB/resources-in-use诊断；不等于每次玩家退出都会出现，也未将其抹去。

本游戏使用本机存档和设置，没有实现账号、云存档、联网排行或自动上传诊断功能。问题报告由玩家自行提交；反馈前可遮挡截图中的个人信息，不需要上传私人存档或整个AppData目录。
