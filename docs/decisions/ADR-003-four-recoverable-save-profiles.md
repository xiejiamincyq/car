# ADR-003：四套可恢复的独立存档

状态：已批准。日期：2026-10-13。

用户需要四个独立栏位、加载、删除和复制，而不是比赛快照。沿用经过验证的 SaveStore v6，避免重新实现成绩/解锁校验；每个位的 `save.cfg`、`.bak`、`.tmp` 放在独立目录。登记仅保存当前位和迁移完成标识。

首次升级从旧单档复制到1号，保留旧原件。登记标识防止删空后反复迁移。加载只在标题进行；暂停仍只保存当前档。加载前保存可读的当前进度；损坏档停止写入但允许换档，避免用默认数据覆盖原件。

删除和覆盖复制先确认，原目标目录移到 `save_slots/recovery`。复制先在暂存目录写入并重读校验，再发布；失败恢复目标原目录。删除当前先更新登记为0，失败还原目录；成功后停止自动保存。覆盖当前成功后重载内存，避免旧内存覆盖副本。

登记主文件恢复到旧指针时必须检查其目录仍存在，不能自动重建已移至恢复目录的栏位。显示当前状态与原始健康状态，不能把备份恢复/损坏藏在“当前”标记后。全部操作以1–4范围为边界，陈旧会话登记不符则禁止写入。

未采用四个不带备份的平面文件，也不物理清除旧目标。恢复目录保留真实文件，可由退出游戏后的人工备份/恢复处理；本次未增加自动垃圾回收或中途读档。此设计不声称完全覆盖断电、磁盘损坏或外部进程并发写入。
