# N6 第三轮 A：路面接入验证

## 范围与结论

用户选择第三轮 A 后接入四关低磨损、柔和环境光路面。海岸为冷蓝细沥青，港区为错缝工业混凝土，山道为湿冷粗沥青，日出为暖灰细沥青。没有修改车辆操控、NPC生成、油耗、碰撞、评分或玩家存档。

技术检查通过；人工动态试玩待确认。不进行打包或发布。

## 实现与审查

- `PavementSurface`独立承担材质绘制，主场景只添加调用；实体层顺序仍为路面、白线/特效、道具/障碍、车辆。
- 四张780×960纹理由固定种子程序生成，纵向周期噪声，全部RGB首尾边界连续。横纵尺寸保持道路逻辑坐标，不随机裁切背景。
- 地面纹理和路肩标记为世界静止。审查发现RunState距离是速度积分×0.1；先用失败测试复现慢10倍，再补偿×10。回归覆盖真实RunState推进、暂停、0/80/200/400/500速度和循环边界。
- 高对比模式绕过纹理与环境光层；未知/缺失材质回退原有纯色道路。
- 环境光从既有背景近路侧取样并纵向平滑，向道路中心衰减，独立跟随背景序列。光不是地面实体。
- 纹理与光照资源按背景路径/侧别缓存；未引入外部依赖、联网运行时或存档结构变更。此处没有独立性能基准，不宣称帧率验收。
