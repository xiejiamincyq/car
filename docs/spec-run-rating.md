## 2026-10-07 RC3：动态金币目标与巡航时间

本段覆盖下方历史固定目标，权重和失败赛程上限不变。金币目标采用 `ceil(本局实际生成金币数×90%)`；错过仍计数，终点后才到达玩家的币不生成，重开计数清零。零生成时金币项0分，无免费满分。结果卡显示与评分实际使用同一门槛。

时间目标使用最慢车型普通极速按RunState的距离单位换算，不另留加速宽限：`本关米数/(700×0.1)`。4km参照57.14秒，现有四关45.71/48.57/47.14/51.43秒。倒计时和暂停仍不计时，超载能改善成绩但不放宽目标。保留v6已有历史记录，不追溯重算或清空；旧S级不能当作新规则已验证。

## 2026-10-01 N5：未完赛评分

用户批准新增目标并继续实现。完赛原算法不变；未完赛也显示等级、总分和四项分数，并明确标记未完赛及赛程进度。

令 p = clamp(实际距离 / 本关总距离, 0, 1)，T 为本关目标用时、t 为本局用时：

- 用时原始分 = round(40 × p × clamp(2 − t / (T × p), 0, 1))；零进度时为 0。
- 超车原始分 = round(20 × clamp(超车数 / 整场目标超车数, 0, 1))。
- 避撞原始分 = round((20 − 4 × min(5, 碰撞次数)) × p)。
- 金币原始分 = round(20 × clamp(金币数 / 整场目标金币数, 0, 1))。
- 总分上限 = floor(99 × p)。若四项之和超出上限，四项同比例缩放并使用最大余数法分配整数，使显示分项之和准确等于总分。

例如 50% 进度、30 秒（全程目标60秒）、超车5/10、金币30/60、无碰撞：原始四项20/10/10/10共50，按49分上限折算为19/10/10/10。拖延时间不会增加用时分；零进度即使刷超车和金币，总分也为0。燃油耗尽、完整度失败和外部超时结果使用相同算法，不新增超时玩法。

失败评分只保留在本局结算和重开前的内存中，不写入最佳完赛评级。原有街机得分榜、职业过程统计和赛道最高街机得分仍按既有规则保存；最快完赛时间、奖牌与解锁不因失败获得。此设计沿用 v6 存档格式，不引入新迁移。

验证：81项全量回归通过；失败评分覆盖进度0/25/50/99%、分项求和、刷分上限、非法输入、三种失败原因。主场景与持久化验证失败不覆盖最佳完赛评级且不授予奖牌。720p/1080p中英文结果截图与键盘焦点检查通过；人工试玩待确认。

2026-09-08：B2 碰撞仿真与难度损伤倍率人工试玩通过。此规格细化既有评分计划，不改变碰撞、奖牌或解锁规则。

## 计算规则

仅完赛且比赛用时有效时评级，失败局不授予等级。用时采用比赛累计时间，不含倒计时与暂停。

- 时间分：`round(40 × clamp(2 − 用时 / 基准时间, 0, 1))`。基准内满分，两倍基准及以上为零。
- 超车分：`round(20 × clamp(超车数 / 目标超车数, 0, 1))`。
- 避撞分：`max(0, 20 − 4 × 有效碰撞次数)`。沿用碰撞系统的接触去重，不按每帧重复计数；锥桶有效碰撞也计入。
- 金币分：`round(20 × clamp(金币数 / 目标金币数, 0, 1))`。
- 各分项分别四舍五入后相加，满分100。S≥90、A≥80、B≥70、C≥60，其余D。
- 未使用完整度损伤倍率折算碰撞次数；简单0.2、标准0.5、困难1.0只作用于完整度损伤。

## P6 B布局与新增油耗倍率

用户批准B四项成绩卡。日常油耗=基础油耗×难度倍率×（阻力负荷+正加速度负荷）；简单0.8、标准1.2、困难2.0。重复切换/配置难度不叠乘。超载固定15%成本保持原规格，完整度损伤倍率保持0.2/0.5/1.0。

批准新验收前的燃油预算审计覆盖恒定极速/从280加速两个工况×三难度×四赛道×六车型，共144组合；不拾取沿途燃油，但包含检查点自动补给。7个困难组合未完赛，另外6个组合剩余油量不足5。例：困难driftwing加速后在日出快线3306.8/3600米耗尽燃油。简单/标准未发现此预算违例。该轮保留旧验收时，全量回归报告了燃油预算失败，未将其误报为通过。
