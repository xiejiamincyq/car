# 碰撞仿真 S1–S4

批准方案落实（2026-09-05）。保留简化街机模型，不模拟现实事故伤害。

- 统一用 HUD km/h 计算冲击。世界纵向速度乘0.42；横向像素速度先除道路滚动系数，再乘0.42。屏幕向上为前进。
- NPC接触速度从该帧真实位移还原，包含等待、避让及冲量；巡航设定只决定目标速度，不能拿等待中的超车车巡航920直接计伤。
- 碰撞法线由接触轴的归一化穿入深度决定，指向对方；有效速度=max(0,相对速度·法线)。
- 3/10/30/60/100/150/200 km/h 对应0/1/4/11/23/40/60点，分段线性插值；60为基础曲线上限，部位和质量系数随后应用。
- 侧面系数1.15，车尾0.85，正面1.0。质量系数=clamp(2×对方质量/(双方质量之和),0.7,1.4)。固定物取质量系数1.4。
- 最终完整度损失再乘难度倍率：简单0.2、标准（中等）0.5、困难1.0。统一作用于NPC、施工实体和锥桶；不缩放碰撞冲量、减速或碰撞次数。
- NPC质量：普通1.0、厢式1.3、卡车2.5。玩家潮汐装甲1.3；driftwing、flashpoint为0.9，其他1.0。防护由旧车型碰撞耐受配置映射为clamp(260/原碰撞减速,0.85,1.15)。
- 冲量沿法线，玩家分担接近速度×对方质量占比×0.9；固定障碍承担全量。侧向推动限制120像素/秒，逐渐消退。NPC纵向偏移限幅100内部速度单位，经车体/整道墙检查后应用，90单位/秒恢复巡航。
- 锥桶质量0.01，冲量额外缩放0.08，伤害=min(2,基础伤害×0.035)。同一锥桶只消费一次。
- NPC接触持续到实际分离（5像素迟滞），仅首次接触结算；施工实体按整片区域接触去重。跨物体保护0.15秒。暂停时计时冻结，重开清空状态。第一版不增加持续刮擦磨损。
- 100/70/30/20完整度对应极速系数1/.92/.78/.72，转向系数1/.88/.68/.60；节点间插值，低于20失败。超出新的极速时通过阻力减速，无瞬间压速。
- 裂痕位置对应最近撞击方向；保留轻烟、重烟和火花，减少闪烁模式取消抖动。

兼容说明：CollisionResponder旧固定减速接口和VehicleIntegrity.damage_for_impact仅保留给旧调用/单元测试；实际比赛全部使用ImpactModel。旧8%固定减速不再叠加。

验收：纯模型、停车被追尾、持续接触不重复、锥桶上限、平滑性能、冲量交通安全、全量回归及固定种子人工试玩。边界覆盖是有限模拟，不是无限种子的证明。

验证记录：72项全量测试通过；最后NPC真实速度修正后，`test_main_integrity`及`test_impact_traffic_safety`再次通过。冲量交通测试10种子×600步，画面检查 `tmp/impact-simulation-720.png`。首次整套运行有单个Godot测试进程异常退出，单项和整套复跑通过；仍有既有退出资源清理告警。人工驾驶手感待确认。
