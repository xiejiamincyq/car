# 0.3.0 本机发布与回滚检查清单

> 2026-08-09 范围决策继续有效：用户只要求游戏在当前电脑可运行，因此三人试玩和第二台 Windows 机器兼容性不是发布阻断项；这不代表其他电脑已经验证。

## 发布候选验证

- [ ] `project.godot`、标题页和 Windows 产品版本均为 `0.3.0`，文件版本为 `0.3.0.0`。
- [ ] Godot 4.7 全部自动测试零断言失败，包括 20 种子 × 3 车道 × 3 速度的 300 秒压力模拟。
- [ ] 使用全新用户目录完成候选 EXE 首启和退出，原有玩家存档不被测试污染。
- [ ] 标题、难度、倒计时、驾驶、Space 暂停/继续、重开、失焦、失败、通关、结算和返回标题流程由自动测试覆盖。
- [ ] `GO`、低燃油、碰撞、检查点、封路预警/确认和通关反馈保持可用。
- [ ] 导出过滤器排除 `tests/*` 与 `art/source/*`，包内仅放运行文件和玩家说明。
- [ ] EXE 与 ZIP 的大小、SHA-256、Godot 版本和源码提交记录在 `docs/builds/0.3.0.md`。
- [ ] 当前开发机完成人工键盘试玩并明确批准发布。

## 明确不纳入 0.3.0 本机版

- 三人平衡试玩和第二台 Windows 机器兼容性验证。
- 手柄、移动端、联网、云存档、排行榜和背景音乐。
- 对《Road Fighter》受版权保护素材或关卡内容的直接复制。

## 生成与发布

1. 导出到 `exports/0.3.0/package/NeonCoastRush.exe`。
2. 将 `docs/release-notes-0.3.0.md` 复制为包内 `README.md`。
3. 生成 `exports/0.3.0/NeonCoastRush-0.3.0-windows.zip`。
4. 在 `docs/builds/0.3.0.md` 记录构建证据和校验值。
5. 人工验收通过后再创建并推送不可变 Git 标签 `v0.3.0`。

## 已知限制

- 仅保证当前 Windows 10/11 x64 开发机和键盘流程。
- 成绩与设置保存在本机用户目录，不提供跨机器同步。
- 没有背景音乐；声音由程序化音效构成。
- 若干无头 UI/音频测试退出时可能报告既有 ObjectDB 清理警告；候选 EXE 首启与正常退出必须无运行时故障。

## 回滚

1. 停止使用发生阻断问题的 `0.3.0` 构建，保留原文件、版本号、日志和校验值。
2. 使用 Git 标签 `v0.2.0` 与 `exports/0.2.0/` 中已验证的本机包恢复上一稳定版本，不覆盖旧校验值。
3. 记录复现步骤、Windows 版本、显卡/驱动、日志和截图。
4. 在独立修复提交中处理问题，重新运行全部测试和当前开发机冒烟，再生成新版本。
