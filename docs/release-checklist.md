# 0.2.0 本机发布与回滚检查清单

> 2026-08-09 范围决策：用户明确只要求游戏在当前电脑可运行，因此三人试玩和第二台 Windows 机器兼容性不再是发布阻断项。该决定不代表已经验证其他电脑。

## 已完成验证

- [x] `project.godot`、Windows 产品版本均为 `0.2.0`，文件版本为 `0.2.0.0`。
- [x] Godot 4.7 全部 40 项测试零断言失败。
- [x] 20 种子 × 3 车道 × 3 速度的 300 秒压力模拟通过。
- [x] 全新用户目录首启成功；存档写入、读取、迁移和损坏恢复由自动测试覆盖。
- [x] 当前开发机完成可见窗口试玩；用户回复“继续”，试玩进程正常退出且无残留。
- [x] 标题、三档难度、倒计时、驾驶、暂停、重开、失焦、失败、通关、结算和退出流程通过。
- [x] `GO`、低燃油、碰撞、检查点及封路声音反馈可用。
- [x] 封闭车道形成实体路障，强闯会推回、降速并中断连击。
- [x] 1280×720 与 1920×1080、窗口与全屏布局通过当前开发机验收。

## 明确不纳入 0.2.0 本机版

- [x] 三人平衡试玩：由用户取消发布阻断要求，未执行，不得表述为已经通过。
- [x] 第二台 Windows 机器：由用户取消发布阻断要求，未验证其他硬件兼容性。
- [x] 手柄、移动端、联网、云存档和背景音乐：不在本版本范围。

## 生成与发布

1. 导出到 `exports/0.2.0/package/NeonCoastRush.exe`。
2. 将 `docs/release-notes-0.2.0.md` 作为 `README.md` 放入包内。
3. 生成 `exports/0.2.0/NeonCoastRush-0.2.0-windows.zip`。
4. 在 `docs/builds/0.2.0.md` 记录 EXE/ZIP SHA-256、Godot 版本和构建提交。
5. 创建 `v0.2.0` Git 标签；后续原创美术在新开发版本中进行，不覆盖该里程碑。

## 已知限制

- 仅保证已验收的当前 Windows 10/11 x64 开发机和键盘流程。
- 成绩与设置保存在本机用户目录，不提供跨机器同步。
- 0.2.0 没有背景音乐；游戏内仍以程序化几何视觉为主，原创位图美术在下一阶段集成。
- 若干无头 UI/音频测试退出时会报告既有 ObjectDB 清理警告；发布压力回归、候选 EXE 首启及人工退出未观察到运行时故障。

## 回滚

1. 停止使用发生阻断问题的构建，保留原文件、版本号和校验值。
2. 切回 `0.2.0-rc.1` 的已验证本机构建，不覆盖旧文件或改写旧校验值。
3. 记录复现步骤、Windows 版本、显卡/驱动、日志和截图。
4. 使用独立修复提交，重新运行全套测试和当前开发机冒烟后生成新版本。
