# 0.1.0 发布与回滚检查清单

## 发布前

- [ ] 工作区干净；确认构建产物只在 `exports/`，没有被暂存。
- [ ] 使用 Godot 4.7 运行全部 `tests/test_*.gd`，结果为零失败。当前 Godot 4.7 无头环境会在两个播放程序化 `AudioStreamWAV` 的场景测试退出时报告 ObjectDB 警告；需确认没有新增警告，并在有音频设备的 Windows 构建中复验。
- [ ] 运行 `tests/test_release_regression.gd`：20 个种子和 300 秒压力模拟通过。
- [ ] 确认 Windows 导出模板已安装，`export_presets.cfg` 的 `Windows Desktop` 可见。
- [ ] 导出到新的空目录，且不覆盖任何先前发布包。
- [ ] 在该目录启动 `NeonCoastRush.exe`，完成：开始、加速/转向、暂停、静音、燃油耗尽、`R` 重开、退出。
- [ ] 在 1280×720 和 1920×1080 下确认 HUD 不裁切；静音时仍能区分车辆、燃油和道路边界。
- [ ] 记录至少三份人工试玩反馈（存活时长、死亡原因、公平性评分、最困惑的操作）。
- [ ] 仅在有可复现证据时调整 `scripts/game_config.gd` 中少量参数，并把调整前后结果写入试玩记录。

## 发布

1. 为导出目录生成校验值，例如：

   ```powershell
   Get-FileHash .\exports\NeonCoastRush.exe -Algorithm SHA256
   ```

2. 将压缩包命名为 `NeonCoastRush-0.1.0-rc.1-windows.zip`。
3. 随压缩包附上版本号、日期、已知限制和操作说明。
4. 在发布说明中明确这是 Windows 试玩候选版本，不承诺存档、联网或手柄支持。

## 回滚

1. 立即停止分发发生阻断问题的构建，并保留其版本号与校验值以便定位。
2. 将下载链接切回上一个已验证压缩包；不要覆盖旧文件或改写旧校验值。
3. 记录复现步骤、Windows 版本、显卡/驱动、崩溃日志和截图。
4. 以独立修复提交处理问题，重新运行全套测试和完整冒烟流程后再创建新候选版本。

## 当前已知限制

- 仅面向 Windows 键盘试玩；未提供手柄、移动端、联网或存档。
- 五分钟压力检查是确定性的逻辑模拟，不替代真机帧率和长时间人工试玩。
- Windows 包须在目标机器上手动验证；当前仓库不分发任何构建产物。
