## 开发机人工冒烟

- [ ] 标题页可选择轻松、标准、困难并开始比赛。
- [ ] 倒计时结束有独立 `GO` 音；`Space` 可暂停、继续并重新倒计时。
- [ ] `R` 在比赛中显示确认框，在通关/失败结算页直接开始新一局。
- [ ] 加速、制动、转向、静音、音量调节、`F11` 全屏和 `Esc` 菜单返回均符合 README。
- [ ] Alt+Tab 在倒计时或比赛中自动暂停；回焦后不会自行恢复。
- [ ] 低燃油、碰撞、近失、检查点、通关和封路可用声音或非颜色提示区分。
- [ ] 封路经历三次预警、正式封闭和解除；封闭时车辆无法驶入，被强闯时会推回、降速并中断连击。
- [ ] 至少各完成一次燃油耗尽失败和抵达终点通关，并检查结算、排行榜和重玩。
- [ ] 在 1280×720 与 1920×1080、窗口与全屏下确认 HUD 和菜单不裁切。
- [ ] 从标题页正常退出，无崩溃或残留进程。

## 三人平衡试玩

使用 `docs/playtests/template.md`，至少三名试玩者分别覆盖轻松、标准和困难。

- [ ] 三份记录均包含首局目标理解、通关与否、局长、结束原因、不可避免碰撞、完成感和重玩意愿。
- [ ] 至少 2/3 试玩者无需口头解释即可说清目标、检查点作用和胜利条件。
- [ ] 标准难度首轮通关率：`___ / ___`。可接受区间在收集首轮数据后由负责人填写：`___%–___%`。
- [ ] 高频反馈已修复并复验，或在发布说明中写明延期原因。
- [ ] 若调整平衡，每轮只修改少量 `scripts/game_config.gd` 参数，并记录前后数据和构建哈希。

## 当前已知限制

- 仅支持 Windows 10/11 x64 和键盘；未提供手柄、移动端、联网或云存档。
- 成绩与设置保存在本机用户目录，不承诺跨机器同步。
- 当前音乐总线仅预留，候选版没有背景音乐；美术仍是程序化占位视觉。
- 自动压力模拟不替代真机帧率、音频和长时间人工试玩。
- 若干无头 UI/音频测试在进程退出时报告既有 ObjectDB 清理警告；发布压力回归和候选 EXE 首启无此警告，仍需通过可见窗口冒烟观察真机退出行为。
- `0.2.0-rc.1` 是候选版，在三人试玩和第二台机器验收前不视为正式发布。
