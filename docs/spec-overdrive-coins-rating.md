# 功能规格：超载、金币路线与完赛评分

## 目标

为 Windows 键盘版加入一条相互支撑的新玩法闭环：玩家双击 `W` 消耗燃油换取短时极速，金币路线引导安全但有取舍的走位，完赛后按时间、超车、碰撞和金币表现获得 `S`–`D` 评分。

成功意味着三个系统不会破坏现有固定世界速度、交通公平性、施工导流、燃油压力、暂停和存档兼容性。

## 已冻结的产品契约

### 超载

- 单位按当前 HUD 口径解释为最高速度增加 `100 km/h`，不是 `100 km/s`。
- 比赛中两次真实 `W` 按下沿间隔不超过 `0.28s` 时触发；按住键、暂停、倒计时和结算不能误触发。
- 启动需要至少 15% 最大燃油；超载在 `4.50s` 内额外逐步消耗最大燃油的 15%。原有阻力与加速油耗继续计算。
- 强度在 `0.35s` 内渐入、保持 `3.65s`、在 `0.50s` 内渐出；最高提供 `+100 km/h` 上限和 `+280 km/h/s` 加速度。
- 不可叠加；结束后冷却 `1.0s`。暂停冻结计时，重开完全复位。
- 碰撞不会直接取消超载；燃油归零、离开比赛或重开会结束。

### 金币路线

- 金币是绝对世界速度为 0 的地面物体，屏幕位移只由玩家速度产生。
- 每组 6–12 枚，间距 55–75px；模板包括直线、缓慢并线、避障、风险线和施工导流。
- 固定局种子产生固定路线；不得与 NPC、燃油、施工核心或底线重叠，不得引导至封闭或不可达车道。
- 每枚金币计数 `+1`、即时得分 `+20`，并可延续现有 Combo；第一版没有商店、磁铁或独立金币连击。

### 评分

- 只有完赛结果授予正式等级；未完赛显示统计但不授级。
- 总分 100：完成时间 40、超车 20、碰撞 20、金币 20。
- 等级：`S >= 90`、`A >= 80`、`B >= 70`、`C >= 60`、其余 `D`。
- 赛道配置提供基准时间、目标超车数和目标金币数；困难度可调整目标，但不能改变公式结构。
- 现有奖牌与解锁保留；奖牌负责进度，评分描述单局驾驶质量。
- 每条赛道保存最佳评分与最佳等级，存档从 v5 安全迁移到 v6。

## 技术栈与命令

- 引擎：Godot 4.7，GDScript。
- 测试：`powershell -ExecutionPolicy Bypass -File scripts/tests/run_tests.ps1 -GodotExecutable <Godot_console.exe>`
- 单测：`<Godot_console.exe> --headless --path . --quit-after 60 --script res://tests/test_<feature>.gd`
- 试玩：`<Godot.exe> --path . --script res://tests/PlaytestLauncher.gd -- neon_coast pulse_gt hard 611`

## 项目结构

- `scripts/overdrive_controller.gd`：双击输入、状态、强度、速度奖励和额外油耗。
- `scripts/coin_pickup.gd`：单枚金币运行时数据。
- `scripts/coin_route_director.gd`：确定性路线模板、生成与安全约束。
- `scripts/run_rating.gd`：纯逻辑评分计算。
- `scripts/main.gd`：只负责各模块接线、碰撞检测和视听调用。
- `scripts/audio/`：超载和金币音效接入。
- `tests/`：每个纯逻辑模块一个专项测试，另有主循环、存档和动态公平性集成测试。

## 代码风格

保持现有显式类型、早返回和纯逻辑模型风格：

```gdscript
func try_activate(current_fuel: float, maximum_fuel: float) -> int:
	if state != State.IDLE:
		return ActivationResult.UNAVAILABLE
	if current_fuel < maximum_fuel * fuel_cost_ratio:
		return ActivationResult.INSUFFICIENT_FUEL
	_start_active_cycle(maximum_fuel)
	return ActivationResult.ACTIVATED
```

## 测试策略

- 纯逻辑单测：双击边界、强度曲线、额外油耗累计、评分阈值、金币模板。
- 集成测试：驾驶临时上限、暂停/重开、HUD、音频状态、拾取一次性结算、v5→v6 迁移。
- 动态模拟：金币路线与 NPC、燃油、施工组合仍至少保留一条可达路线；临时 100km/h 上限纳入制动反应距离。
- 视觉验证：720p/1080p 截图；美术先提供 A/B/C 预览并等待人工选择。
- 人工验证：超载手感、声音层级、金币引导和评分可信度。

## 边界

### 始终执行

- 行为先写失败测试；每个纵向切片全量回归后再提交。
- 固定种子必须可复现；地面物体绝对速度必须为 0。
- 保留减少闪烁、高对比、静音和失焦暂停语义。
- 每个大检查点推送 GitHub、发送提醒并打开试玩界面。

### 需要再次人工确认

- A/B/C 超载和金币视觉方向。
- 首轮超载手感参数。
- 金币路线密度和最终评分阈值。
- 正式 v6 存档与发布候选。

### 禁止

- 不复制其他游戏的图像、声音或具体关卡路线。
- 不引入金币商店、永久升级、磁铁、护盾、跳跃或超载叠层。
- 不用自动测试替代必要的键盘试玩和听测。

## 完成标准

- 双击 `W` 的触发、燃油、速度、暂停和重开契约全部通过自动测试与人工试玩。
- 金币连续、可达、确定性生成，且不会与危险对象形成无解路线。
- 四项评分可解释、可保存，旧存档无损迁移。
- 720p/1080p UI 完整，关键音效可辨，全部测试通过并完成 GitHub 备份。
