# Neon Coast Rush 0.2.0

Windows 10/11 x64 键盘本地正式版。目标是在燃油耗尽前穿过四个赛段并抵达终点；途中需要避开车流、收集燃油并应对临时封路。

## 操作

- `W`/`↑` 加速，`S`/`↓` 制动，`A`/`←` 与 `D`/`→` 转向。
- `Space` 暂停/继续，`R` 重新开始，`M` 静音，`-`/`+` 调音量，`F11` 切换全屏。
- `Enter` 确认菜单，`Esc` 返回或取消；从标题页“退出”按钮关闭游戏。

## 注意

- 封路会先三次预警，再形成不可通行的横向路障；强闯会被推回、降速并中断连击。
- 成绩、设置和生涯统计保存在本机用户目录。
- 本版本仅保证当前开发机的键盘流程，没有验证其他电脑；不提供手柄、联网、云存档或背景音乐。
- 发现问题时请记录局种子、赛段和复现步骤。
