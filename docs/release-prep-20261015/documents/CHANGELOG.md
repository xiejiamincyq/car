# RC5 玩家更新说明

本准备包复用已验收的0.4.0-rc.5程序，未重新导出、未修改玩法和美术。变化仅为独立Windows便携ZIP和发布准备文档。

## 当前版本已有内容

- 四条赛道、六辆车、三种难度和中英文界面；六车展示图和属性图表，确认后开局。
- 双击任意前进键触发超载；拖尾随车体旋转，金币拾取有音效和反馈。
- NPC独立世界速度、安全变道、施工导流与固定450km/h红色快车；困难模式增加交通与操作压力。
- 全赛道左弧/右弧/S形金币路线及更均衡的左右布局；保持安全限制和原刷新节奏。
- 速度/燃油仪表、完整度与距离进度、小地图和检查点标记；失败也有得分与评级。
- 生涯记录逐局真实得分，结算自动保存；四存档支持加载、复制和可恢复删除，手动保存保留。
