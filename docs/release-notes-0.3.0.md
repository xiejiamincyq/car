# Neon Coast Rush 0.3.0

原创夜间海岸像素风纵向赛车，本版本面向当前 Windows x64 电脑和键盘试玩。

## 操作

- `W` / `↑`：加速；`S` / `↓`：制动。
- `A` / `←`、`D` / `→`：转向。
- `Space`：比赛中暂停/继续；菜单焦点在按钮上时确认。
- `Enter`：菜单确认；`Esc`：返回或取消。
- `R`：重新开始；`M`：静音；`-` / `+`：音量；`F11`：窗口/全屏。

## 目标

避开交通和封闭车道，收集燃油，通过三处检查点并抵达 3200 米终点。封路会先发出三连预警，正式封闭后实体路障不可驶入。

## 0.3.0 新内容

- 原创玩家车与五类交通车辆、燃油拾取精灵。
- 可滚动道路、岩岸植被、海面浪花和正式 HUD。
- 加速、制动、拾取、超车、近失、碰撞与通关反馈动画。
- 保留完整难度、存档、无障碍、程序化音效与四赛段通关流程。

## 范围与存档

仅验证当前 Windows 10/11 x64 开发机，不含手柄、联网、云存档或背景音乐。成绩和设置保存在本机 Godot 用户目录；删除存档前请自行备份。
