## 启动

完整解压游戏包后，双击包内 EXE。EXE 与配套同名 PCK 必须放在同一目录，请保留原文件名，不要只复制 EXE。

当前导出配置未启用数字签名，Windows 可能显示“未知发布者”或安全提示。请先核对项目所有者提供的来源及文件哈希；无法确认时停止运行并联系项目所有者。不要关闭 Defender 或其他安全防护。

## 操作

| 按键 | 功能 |
|---|---|
| W / ↑ | 加速 |
| 快速按放两次前进键 | 超载；可用 W、↑ 或交替使用，需先松开前进键，燃油足够且冷却结束 |
| S / ↓ | 制动 |
| A、D / ←、→ | 左右转向 |
| Space | 暂停 / 继续 |
| R | 重新开始；比赛中会先确认，确认后丢失本局未完成进度 |
| M | 静音 / 恢复声音 |
| F11 | 切换全屏 |
| - / = | 减少 / 增加总音量 |

菜单使用方向键选择、Enter 确认、Esc 返回或取消确认。设置中可用 Tab 切换选项。标题的“开始比赛”先进入赛道选择，再选赛车并确认开赛；难度在标题调整。

## 玩法

穿越车流与施工区域，抵达所选赛道终点。油罐补充燃油，维修补给修复完整度，金币增加得分；碰撞会损伤车辆，受损会影响极速与转向。开局 30 秒保护期后燃油耗尽，或完整度低于 20%，会导致失败。

结算展示用时、超车、避撞与金币表现。失败也显示本局分项、进度和分数上限，但不算完赛、不发通关奖牌，也不更新赛道最佳评级。通关逐步解锁后续赛道；更多赛车的解锁条件可在车库查看。

## 保存与反馈

设置和比赛结算数据自动保存；不会恢复中途驾驶状态。Windows 默认存档目录为 `%APPDATA%\Godot\app_userdata\Neon Coast Rush\`，主档为 `save.cfg`，备份为 `save.cfg.bak`，不在 EXE 目录中。备份或迁移前请退出游戏并保留这两个文件。

- “已恢复备份存档”：本次使用了备份数据，可能较上次进度旧；不要删除现有主档或备份。
- “无法读取存档 · 本次进度不会保存”：仍可本次游玩，但退出后新进度可能丢失。先保留原存档，再检查目录可读写权限和磁盘空间；问题解决后重新启动。
- “保存失败 · 本次进度尚未保存”或设置显示“仅本次生效”：不要把本次改动当作已保存。先截图、保留存档副本并检查目录权限和磁盘空间；持续失败请反馈。
