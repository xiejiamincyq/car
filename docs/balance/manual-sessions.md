## 运行方法

在项目根目录 PowerShell 执行：

```powershell
./scripts/tests/start_balance_playtest.ps1 -Session 1
```

把 `1` 改成 `2` 至 `10` 可启动对应固定组合。只启动一局，不会自动替玩家驾驶。首次直接进入倒计时；Space暂停，W加速、S减速、A/D转向、双击W超载。设置从暂停页进入。

专用入口关闭生涯与设置写回，全部选车选关仅作用于该次进程。正式启动入口不记录这些日志，不受影响。按R重开的随机种子会变化，以日志实际种子为准；下表固定种子用于首次启动和问题复现。

本地结果目录：`%APPDATA%/Godot/app_userdata/Neon Coast Rush/playtests/`，每次启动生成独立的 `session-*.jsonl`，每行一局。记录关卡、车、难度、实际种子、用时、距离、得分、金币、超车、碰撞次数、油量、完整度、结果及失败原因。只在本机保存，不自动上传，不记录按键或其他个人信息。

- `clear`：完赛；`failed`：游戏判定失败；`aborted`：中断/重开/退出，不混入完整局通关率。
- `source=interactive_unverified` 仅说明使用可见试玩入口，仍需本人确认是实际键盘驾驶。
- `source=automated_headless` 为自动化测试，不计入人工样本。
- 强制结束进程/断电无法保证写出中断记录。写盘失败会提示且不阻断驾驶，不能把未写出的结果视为已记录。
- 日志不能判断失败是否公平；以下主观问题仍需反馈。
