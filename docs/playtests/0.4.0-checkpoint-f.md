## 每局观察清单

- [ ] HUD 显示的赛道效果、车辆手感、难度和种子与表格一致。
- [ ] 左右背景均向玩家方向下移，无反向、停顿、异常放大或明显拼接线。
- [ ] NPC 为近俯视视角；玩家和 NPC 转向倾斜方向正确，车体没有压扁。
- [ ] 随机变道只在可见区域发生，并在横移前完成转向灯警告。
- [ ] 后方高速车遇到慢车时能选择安全路线，不形成不可避免的移动墙。
- [ ] 施工锥桶导流方向符合开放车道，锥桶相对地面静止且前后连续；碰撞只产生有限惩罚。
- [ ] 燃油不与 NPC 在底线重合，能够在至少一条可达车道拾取。
- [ ] 检查点提示音、施工预警音、碰撞音和结算内容完整；结算选项没有被裁切。
