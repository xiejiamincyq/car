# 统一界面实施与验收

日期：2026-10-12。批准依据：`tasks/plan-ui-global-20261012.md`。当前状态：U0–U5技术验收完成；人工试玩尚未完成。

## 实际改动

- 标题落地B海岸巡回徽章，保留右側道路构图。开始比赛优先，排行榜/保存、设置/说明双列，退出低强调；七项动作有明确Tab与方向键路线。
- 暂停设置、危险操作确认框拥有顶层输入；Space/R不越过面板恢复比赛。子菜单返回原入口焦点，明确继续才恢复倒计时。
- 选车改为大预览、六车缩略图、持续选中标记与单独确认。锁定仍可浏览但不能开局，解锁条件保留。车型参数图保留真实极速单位，其他运动参数标明相对能力，防护系数注明不含质量因素。
- 四条赛道用已有环境纹理的固定Atlas区域作菜单缩略图；不改变赛车时的背景序列、比例或随机算法。
- 设置保留三个音量渠道和所有原开关，分画面/语言、辅助/效果；正常冗余保存说明隐藏，保存异常仍显示。排行榜用排名、得分、难度、距离对齐列，空榜如实显示。
- HUD精简重复中英和无事件COMBO文字，速度/燃油仪表缩小归位，增加实际燃油长条，完整度和距离保持长条；低油颜色乘算已纠正。结算突出评级和四项明细，两个返回动作并列；算法不变。
- 手动保存成功仅在真实写入成功后出现，2.5秒后消退；失败/读取异常不自动消失，也不增加中途读档。

共享视觉采用海岸深蓝、青色功能色和金色主操作；键盘焦点为独立浅色外框。没有安装新依赖、生成新车辆素材、改变交通/评分/碰撞/燃料数值，或恢复网页监督。
