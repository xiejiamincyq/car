# Neon Coast Rush — 0.4.0 Windows x64 正式版

程序版本0.4.0；Windows数字文件版本0.4.0.6（构建序号）。未签名便携版。

## 开始游戏

完整解压，进入NeonCoastRush-0.4.0-Windows-x64文件夹，运行NeonCoastRush.exe；EXE与NeonCoastRush.pck必须同目录。不要直接在压缩包内运行。无需Godot编辑器、Python或Node.js。

W/↑加速，S/↓制动，A/D或左右箭头转向；双击前进键超载；Space暂停/继续；F11切换全屏。选车后按确认开赛。详细玩法见PLAYER_GUIDE.md，问题处理见SUPPORT.md。

## 存档与安全

四栏位存档仍为v7，位于`%APPDATA%\Godot\app_userdata\Neon Coast Rush`。结算自动保存，手动保存保留。0.4.0不改变RC5存档格式和应用名称。升级前先退出并备份整个上述目录；不要用旧程序覆盖新档。删除解压目录卸载程序，存档默认保留。

EXE未签名，Windows可能显示未知发布者或阻止运行；不要关闭安全功能。当前只在本机Windows x64验证，不保证所有显卡、驱动或Windows版本兼容。验证范围见RELEASE_STATUS.md，音频问题及反馈步骤见SUPPORT.md。
