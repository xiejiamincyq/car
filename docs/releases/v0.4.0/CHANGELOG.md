# 0.4.0 正式版更新说明

2026-10-16：从RC5升级为0.4.0正式版，同步游戏内版本、Windows产品版本、仓库文案和包内说明，重新导出新包。Windows数字文件版本0.4.0.6延续RC5后的构建序号。

本次不改玩法、美术、难度、应用名称或v7存档格式。旧RC5标签和附件保留，不覆盖。

## 游戏内容

- 四条主题赛道、六款赛车、三种难度，中英文界面与独立音乐。
- 独立速度NPC、变道预警、施工导流、固定450km/h红色快车。
- 双击前进键超载，左弧/右弧/S形金币路线、燃油与维修补给。
- 仪表HUD、小地图和检查点，未完赛也计算得分与评级。
- 生涯逐局成绩，四存档加载、复制、可恢复删除，结算自动保存与手动保存。

## 检验与限制

旧RC5已有用户本机试玩接受及177项冻结技术回归。0.4.0另做版本/菜单/存档专项、实际PCK资源检查、干净解压和隔离EXE短启动；这不是新一轮人工驾驶验收或长时性能证明。详情见RELEASE_STATUS.md。

此前用户跳过的四关逐帧性能、30分钟有效驾驶、20次重开/返回趋势及剩余正常新旧档胜负补证保持SKIPPED_BY_USER，不记PASS。程序未签名，不承诺固定帧率、长期零内存增长或零退出告警。
