# Neon Coast Rush 0.4.0-rc.5

Windows x64 键盘赛车游戏。项目所有者已批准公开发布；此版本仍标记为RC预发布版，不升级为1.0稳定版。

## 游戏内容

- 四条主题赛道、六款可选车辆与三种难度；选车可查看展示图和性能图表，确认后开赛。
- NPC具有独立世界速度、可见变道预警和转向动画；施工导流、锥桶及固定450km/h红色快车带来不同驾驶压力。
- 双击任意前进键触发超载，带加速音效与随车转动的拖尾。
- 连续金币路线支持左弧、右弧与S形，结合交通避障和可达性限制布局；设有燃油与维修补给。
- 速度/燃油仪表、完整度、进度条、小地图与检查点标识；完赛和未完赛均有评分，生涯记录逐局得分。
- 四个存档栏位支持加载、复制与可恢复删除；结算自动保存，手动保存保留。
- 中英文界面，支持键盘导航、音量设置、高对比与减少闪烁选项。

## 下载与运行

下载附件`NeonCoastRush-0.4.0-rc.5-Windows-x64.zip`，完整解压后运行文件夹内的`NeonCoastRush.exe`。EXE与PCK必须保持同目录；无需安装Godot编辑器、Python或Node.js。

W/↑加速，S/↓制动，A/D或←/→转向；双击前进键超载，Space暂停/继续，F11切换全屏。更多说明见包内PLAYER_GUIDE.md。

SHA256SUMS.txt提供下载校验。例如在PowerShell中运行：

```powershell
Get-FileHash .\NeonCoastRush-0.4.0-rc.5-Windows-x64.zip -Algorithm SHA256
```

## 存档与回退

存档位于`%APPDATA%\Godot\app_userdata\Neon Coast Rush`，不在游戏解压目录。当前格式为v7。升级或回退前请退出游戏并备份整个存档目录；不要用旧程序覆盖新格式存档。复制/删除存档请核对游戏内确认框。

发现阻断问题时，先停止使用该包，保留错误信息、版本与复现步骤，再使用自己保留的已验证旧程序和与之匹配的旧存档副本；不要混用EXE/PCK。本次发布未覆盖原本机交付和旧ZIP。
