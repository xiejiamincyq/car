# 菜单美化与金币方向修复验证

## 范围

- 保留用户已确认的金币双音铃声及混音参数，不改音频实现。
- 金币碎光改为屏幕下方的车尾扇形拖尾。此前全圆散射并叠加负 Y 偏移；新增方向断言在旧实现上失败，修复后通过。+1 是信息浮字，保持向上浮出与文字正向。
- 统一启动、巡回选关、选车、设置、操作说明、暂停、结算与确认弹窗：深蓝底、青色卡片边框、金色主要操作、独立危险操作与明显键盘焦点。

- 设置/结算/车库采用紧凑间距，保留原节点路径与信号连接。
