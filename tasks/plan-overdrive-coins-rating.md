# 超载、金币路线与完赛评分实施计划

规格来源：[`docs/spec-overdrive-coins-rating.md`](../docs/spec-overdrive-coins-rating.md)。

预计总用时 20–31 小时，不含人工试玩与 A/B/C 美术选择等待时间。Terra 负责常规接线和 UI，Sol 负责状态机、公平性、评分、迁移与复核，图像模型只在预览获批后制作原创素材。

## 依赖关系

```text
规格与参数冻结
  ├─ 超载状态机 ─ 驾驶/燃油接线 ─ 视听表现
  ├─ 金币路线安全模型 ─ 拾取闭环 ─ 视听表现
  └─ 运行统计 ─ 评分模型 ─ 存档 v6 ─ 结算 UI
                                      ↓
                              综合平衡与发布验证
```

## P0：规格与任务冻结（0.5–1小时，Sol）

- 保存产品契约、接口、测试策略和范围边界。
- 在总任务列表增加本功能的阶段状态。

验收：单位、持续时间、燃油、评分和不做事项无歧义。

## P1：超载核心纵向切片（2–3小时，Sol）

- 新增 `OverdriveController`，覆盖双击、状态、强度、冷却和额外油耗。
- 扩展 `DriveController` 的临时速度/加速度参数。
- 在 `RunState` 提供受阶段保护的显式燃油消耗接口。
- 接入主循环、暂停和重开；以现有 HUD 数字作为第一轮可试玩反馈。

验收：双击触发；持续4.5秒；0.7秒渐入、1秒渐出；最高增加100km/h；累计额外消耗15%；不可叠加；暂停冻结；重开复位。

**检查点 A：** 全量测试后推送、提醒并打开困难难度试玩，确认触发窗口、持续时间和燃油成本。

## P2：超载视觉与音频（3–4.5小时，Terra＋图像模型）

- 先生成 A/B/C 三套预览并等待选择。
- 接入喷焰、残影、速度边缘辉光、HUD 状态条和减少闪烁替代表现。
- 接入启动、持续和退出音效，校验关键警报层级。

验收：两种分辨率无遮挡；静音安全；警报不被覆盖。

## P3：金币路线安全模型（4–6小时，Sol）

- 新增金币数据和确定性路线导演。
- 实现五种路线模板及 NPC、燃油、施工排斥区。
- 将金币作为世界静止物纳入速度和动态公平性测试。

验收：固定种子可复现；无重叠、无封路引导、无不可达路线。

## P4：金币拾取闭环（3–4小时，Terra＋图像模型）

- 先生成 A/B/C 金币预览并等待选择。
- 接入吸附、碰撞、计数、即时得分、Combo、HUD、特效和音效。
- 限制活动对象数量并验证一次性结算。

**检查点 B：** 推送、提醒并打开试玩，确认路线是否真正引导走位。

## P5：评分与存档（3–5小时，Sol）

- 增加碰撞与金币运行统计。
- 实现时间40、超车20、碰撞20、金币20的纯评分器。
- 存档 v6 保存每关最佳评分/等级并无损迁移 v1–v5。

验收：边界分数准确；较差结果不覆盖最佳记录；旧档不丢数据。

## P6：结算与双语 UI（2–3小时，Terra）

- 结算显示等级、总分和四项拆分。
- HUD 显示金币和超载状态。
- 完成中英文、高对比、720p/1080p 和键盘焦点验证。

## P7：综合平衡与交付（3–5小时，Sol复核＋Terra修正）

- 四赛道×六车型×三难度固定种子模拟。
- 人工验证超载收益、金币风险路线、评分可信度和声音层级。
- 全量测试、代码审查、GitHub 推送和最终试玩。

**检查点 C：** 人工批准后冻结数值并进入后续发布流程。
