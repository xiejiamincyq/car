# 全界面核验后的改动方案

日期：2026-10-12。状态：方案与预览完成，等待用户批准实施。

## 目标与边界

把现有PC键盘赛车的标题、赛道、选车、设置、排行榜、HUD、暂停、确认与结算统一成协调的成品界面。
不是重新制作游戏，也不是全局安装/启用更多技能。
沿用已批准的A海岸海报布局、B海岸巡回徽章方向和已有车辆、背景素材。
不改交通、难度、评分、碰撞、燃料数值、音乐或存档格式；不启动网页监督、不发布发行版。

这次只检查和制作预览，正式 `scripts/`、`scenes/` 和运行配置保持原状。
预览中的成绩和车辆状态是明确的内存样例，不是玩家存档或真实完赛记录。

核验证据：`docs/validation/ui-global-20261012.md`。
预览总览：`docs/previews/ui-review-20261012/overview.png`。

## 核验结论

| 优先级 | 项目 | 实际发现 | 处理方向 |
|---|---|---|---|
| P0 | 暂停内设置/确认框 | 按Space会从PAUSED进入COUNTDOWN，而设置/确认框仍显示 | 按顶层界面分发输入，遮罩存在时不允许恢复比赛 |
| P1 | 键盘返回 | 排行榜返回能恢复入口焦点；设置/说明返回直接回开始按钮 | 记住入口控件，返回恢复原焦点 |
| P1 | 选车状态 | 金框主要来自焦点；移到确认后选中状态缺少持续标记 | 选中、焦点、锁定三种状态分离，增加“已选”语义标识 |
| P1 | HUD | 重复中英标签、小号字、COMBO就绪常驻；燃油没有下方长条 | 精简无事件信息，保留仪表与新增燃油长条，确保不重复显示左上燃油 |
| P1 | 车型属性 | 加速、制动、转向展示裸数值，含义不明确 | 保留雷达，数值使用明确单位或标明相对能力；不伪造物理参数 |
| P2 | 标题 | 正式场景仍是首版LOGO，七项操作视觉重量接近 | 落地B徽章，开始比赛优先，次操作双列，退出降低强调 |
| P2 | 赛道 | 四个文字矩形辨识度低，未解锁占据主要内容 | 用现有环境素材的固定缩略视图增加辨识，保留清晰锁定/解锁条件 |
| P2 | 设置 | 音量后接长列按钮，分组与值的关系不够直观 | 分声音、画面、辅助；保留键盘可达性与实际开关状态 |
| P2 | 排行榜 | 一段居中拼接文本，不易横向比较 | 排名/得分/难度/距离列对齐，首名强调，其余保持白色 |
| P2 | 结算 | 评分已完整，但边框密、小字密，按钮占两行 | 评分优先、四项明细保留；次要数据降级，底部操作并列 |
| P2 | 保存反馈 | 需与统一视觉配套且避免“保存进度”被误解成比赛中途读档 | 保留真实成功/失败提示，普通成功短时提示；不增加中途恢复 |
| P3 | 更新开销 | `_update_hud()`包括菜单文案与音量同步，标题也反复调用 | 测量后做变化检测；不重构驾驶循环，不把观察等同于性能故障 |

## 视觉规范

- 氛围：克制的海岸巡回赛仪表与金属徽章，不转为网页营销风格。
- 深蓝背景 `#081727`，正文 `#E8F1F1`，功能青色 `#66DDD4`，主操作金色 `#EDC77D`。
- 主按钮高度52–60；次按钮44–48；间距采用8/12/16/24的基本层级。
- 标题约30，按钮18–20，常用正文16–18，次要标签目标至少14逻辑像素。
- 选中状态用金色边框和明确标识；键盘焦点另用外框。不能只靠颜色区分。
- HUD左右贴边，底板约70%不透明度；左下速度/燃油仪表及燃油长条，右上得分/金币，完整度与距离长条保留。
- 中央道路区域以驾驶为主，不增加常驻说明；必要的红车/施工警告仍优先。
- 中英文分别本地化，不在中文模式每行重复英文；km/h等单位保留。
- 不删除操作说明页、解锁条件、失败原因、危险操作确认和真实存储异常提示。
- 轻量状态过渡约120–180ms；减少闪烁开启时不使用循环闪烁，不扩大动态强度。

预览复用了现有性能图。单位解释、焦点路径重接、所有锁定组合以及实际过渡动画仍属于后续实现，不声称已完成。

## 实施顺序、预计工时和验收

以下为有效工作时间估计，不是保证的墙钟时长。合计约6–9小时，加一次人工试玩。
常规样式可由Terra承担（环境提供时）；输入、状态、安全和回归审查优先Sol。没有相应模型入口时由当前模型完成，不另开网页监督。

### U0：输入安全与焦点恢复（0.75–1小时，Sol）

依赖：无。先给暂停内设置、确认框的Space串透写回归测试，再修输入分发。
预计文件：`scripts/main.gd`，新的菜单输入测试，现有菜单流程测试。

- [ ] 设置/确认框显示时，Space、Enter、Esc不会意外启动驾驶；明确继续比赛才恢复。
- [ ] 返回标题子菜单恢复原入口焦点；取消确认恢复暂停菜单，不重置比赛。
- [ ] 模态状态期间距离、燃油、倒计时不前进；音频按已有规则维持暂停。

验证：真实引擎内按键事件；主菜单→赛道→选车、暂停→设置→返回、暂停→确认→取消回归。

### U1：公共主题与标题（0.75–1.25小时，Terra实现/Sol审查）

依赖：U0。预计文件：`scripts/ui/menu_presentation.gd`，`scripts/ui/title_logo.gd`，`scenes/main.tscn`，标题测试。

- [ ] B徽章落地，不引入未选A/C代码、外部字体或新增图像依赖；保留右侧道路。
- [ ] 所有七项动作仍可达；双列布局键盘邻接和Tab顺序明确，保存成功来自真实写入。
- [ ] 720p/1080p、中英、保存失败/禁用状态无裁切；主按钮与次操作层级明确。

验证：菜单动作、标题布局、保存反馈专项，实际渲染逐张检查。

### U2：选车与赛道（1.25–2小时，Terra实现/Sol审查）

依赖：U1。预计文件：选车/赛道两个场景，两个界面脚本，性能图脚本；测试单独分小批次。

- [ ] 六款车辆都有正确缩略图；浏览不直接开局，明确确认后才启动；锁定车不能启动。
- [ ] 选中标识在焦点移到确认/返回后保持，属性与预览随选择一致。
- [ ] 雷达与能力条来自车型参数；防护系数不冒充总耐撞性（质量也影响伤害）。赛道缩略图不能挡住名字或锁定信息。

验证：六款车型×锁定/可选×双语言；方向键浏览、Tab转确认、Enter确认、Esc返回。
缩略图只用于菜单，固定区域来自已有环境纹理；不改变实际赛道背景序列或裁切规则。

### 检查点一

U0–U2专项与真实图形截图通过，确认风格与交互一致，再做其余界面。

### U3：设置与排行榜（0.75–1.25小时，Terra实现/Sol审查）

依赖：U1。预计文件：主场景、音量设置组件、菜单样式和文案；每批最多约5个文件。

- [ ] 声音/画面/辅助分组清晰，键盘焦点不越过当前面板，所有选项仍可操作。
- [ ] 排行榜空榜、五条记录、七位得分和英文难度均对齐且无截断，不改排序算法。
- [ ] 设置保存、失败反馈、重启读回行为保持；不加入假“已保存”状态。

验证：音量UI、持久化、排行榜入口、空榜/满榜及中英实际渲染。

### U4：HUD、暂停与结算（1–1.75小时，Sol）

依赖：U0/U1。预计文件：仪表HUD、路线小地图、评分卡、菜单样式和文案，按HUD/结算两批落地。

- [ ] 普通/低油/严重损伤/超载/红车/施工场景均可读；界面不挡住危险警告，保留70%底板。
- [ ] 速度与燃油仪表保留、燃油长条补齐，左上不重现燃油；超载/连击仅在有意义时强调。
- [ ] 未完赛评分上限、失败原因、四项评分和返回动作完整；评分数字/算法不变。

验证：极值HUD、两种结果、危险确认及操作导航；四赛道实际视图对照，不把静态预览当驾驶压力验收。

### U5：整体回归与交付（0.75–1.5小时，Sol）

依赖：U0–U4。

- [ ] 全量测试通过；新增输入串透测试和六车型/空满榜覆盖均有终止证据。
- [ ] 720p/1080p、中英、窄窗口留边策略逐图检查；小字清晰，海岸背景不拉伸。
- [ ] 新候选包与对应源码一致；试玩通过后才按原成品计划继续，不覆盖旧RC5或提前公开发布。

测量菜单字符串/样式更新开销，只在有证据的情况下缓存；速度动画等需要逐帧变化的内容不强改成“只用事件”。
