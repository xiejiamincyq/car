# Neon Coast Rush MVP 任务清单

> 这是 0.1.0-rc.1 纵向切片的历史清单。未完成的产品化工作已经重新拆分到 [`plan-foundation.md`](plan-foundation.md)。

- [x] 验证 Godot 4、Windows 导出模板与目录规范

- [x] 建立集中式游戏参数表
- [x] 建立试玩记录模板

- [x] 完成 60 秒驾驶原型验证

- [x] 完成十次随机开局的公平性检查
