# 《高速突围》MVP 任务清单

## 阶段 0（0.5–1 天）

- [ ] 验证 Godot 4、Windows 导出模板与目录规范
- [ ] 确认原创主题和参考边界
- [ ] 建立集中式游戏参数表
- [ ] 建立试玩记录模板

## 阶段 1（1.5–2 天）

- [ ] 创建主场景与 PC 键盘输入映射
- [ ] 实现玩家车速度、转向与道路边界
- [ ] 实现速度驱动的道路纵向滚动
- [ ] 完成 60 秒驾驶原型验证

## 阶段 2（2.5–3.5 天）

- [ ] 实现可固定随机种子的交通生成器和对象池
- [ ] 实现慢速直行、预示变道、高速追越三种交通行为
- [ ] 实现碰撞、无敌、减速、震动与占位音效
- [ ] 完成十次随机开局的公平性检查

## 阶段 3（2–3 天）

- [ ] 实现 RunState、燃油、距离与分数
- [ ] 实现燃油补给与渐进难度曲线
- [ ] 实现开始、暂停、结算与重开
- [ ] 完成十局完整流程回归

## 阶段 4（2–3 天）

- [ ] 制作并集成原创视觉资源
- [ ] 集成原创/授权音效与音量设置
- [ ] 完成 720p/1080p 可读性检查

## 阶段 5（2–3 天）

- [ ] 添加重开、燃油、出生规则的自动检查
- [ ] 完成 20 局随机种子回归和 5 分钟压力测试
- [ ] 完成至少 3 人试玩与一轮平衡调整
- [ ] 导出并验证 Windows 试玩包
