# R5被动性能取证补片

范围：落实plan-product-ready.md的性能采样入口，补实际release的阶段和节点/对象趋势证据；不是新增玩法或自动驾驶。R5/R6原门槛不变，当前RC1不覆盖、不关闭、不注入输入。网页已取消。

## 决策与边界

现有PresentMon能采实际呈现间隔和进程内存，不能提供应用内对象数或比赛状态。采用单个RefCounted采样器，通过固定开关`NEON_COAST_PERF_CAPTURE=1`显式启用；默认不创建文件、不轮询监测、不新增节点。仅写本地user://performance/唯一会话JSONL，路径不能由环境变量/玩家输入指定，不联网、不读取键盘、不使用随机源、不改v6存档或音画/玩法规则。

一次启用后按单调墙钟约1Hz采样，长帧不追补积压；阶段或本局编号改变补立即样本。记录有限白名单：阶段/赛道/车款/难度、速度/赛程、施工/超载状态、局编号、窗口尺寸/焦点，以及FPS和对象/节点/资源数量。静态内存/孤立节点在release不可用，用null标注；不当作0/无泄漏。每行有schema/会话/PID/单调时间，刷新文件，写失败停止采集但不停止游戏。验收数据仅保留在隔离APPDATA下，不加入玩家包。

2026-10-04切片1：采样器本体和独立测试已实现，默认off不产生IO；限流、长帧、状态切换、白名单、时钟倒退、不可用release指标、重复启动/关闭、不可写目录及中途IO错误停用均专项通过。最初缺少实现红测失败1；故障边界首试因super方法尚不存在解析失败，调整为实际文件IO边界夹具后红测准确失败2，再实现错误处理后通过，所有失败日志保留。不可写目录的引擎ERROR是主动故障注入，不称零告警。尚未接入Main、未导出rc.2，不能宣称实际release节点采集或R5通过；接入后才做完整回归及新包验证。
