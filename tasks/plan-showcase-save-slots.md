# 车辆展示图与四存档位

日期：2026-10-12。范围：用户直接要求的左侧展示图和四个存档栏位；不更改右侧六车卡片、比赛贴图、车型性能或驾驶算法。

## 规格与已确认项

Windows/Godot 4.7/GDScript，PC键盘与鼠标。展示图逐车使用 `art/source/vehicles/*_chroma.png` 原始源图；用户已确认这些就是所指概念图，未显示的侧面允许合理补全。车头正北，从北偏西约30°左前方平视；车展式完整车体、透明背景、同一构图与画风。仅用于左侧展示，等比适配、不沿用俯视贴图旋转/压缩。

存档为四套独立成绩、生涯、车型/赛道解锁、评级和设置，不是比赛中途存盘。标题提供存档管理，暂停仅保存当前进度，驾驶期间不能切换/删除/复制。加载空位可建立新档；重启记住当前档。四栏展示当前/空/损坏/备份恢复状态及真实进度摘要。

复制有明确源与目标：源保持不变，非空目标必须确认覆盖。删除必须确认，整个位的主文件及备份移入恢复目录，不物理清空玩家进度。删除当前档后停止自动保存并提示选择栏位，防止旧内存把删档写回来。复制覆盖当前档后刷新内存，不能拿旧内存覆盖新副本。

旧 `user://save.cfg` 第一次升级复制到1号位，原文件及备份保留。登记迁移完成，重启与删空后不重复迁移，避免“已删档复活”。沿用现有SaveStore格式与校验/备份机制；读错或损坏不冒充空档，不用默认进度覆盖。所有自动测试使用独立临时目录，不操作正式玩家文件。

## 结构、代码与命令

- 新展示素材：`assets/vehicle_showcases/`；独立展示图目录类，不改原车辆目录中的比赛贴图。
- 四位存储：`scripts/save_slots.gd`；每个位有独立目录及SaveStore文件，登记文件仅记录当前栏位/迁移状态。
- 界面：`scripts/ui/save_slots_screen.gd`；事件驱动的操作与确认，容器布局，初始与返回焦点明确。
- 测试：`tests/test_save_slots*.gd`、`tests/test_vehicle_showcases.gd`；文档：`docs/validation/`和素材生成记录。
- 风格沿用 `func load_slot(index: int) -> bool`、明确失败状态、范围校验与小函数，不把文件IO塞进逐帧驾驶更新。
- 专项：`./scripts/tests/run_tests.ps1 -TestFilter test_save_slots.gd`；全量：`./scripts/tests/run_tests.ps1`。GUI用原生Godot脚本渲染，不用Computer Use。
