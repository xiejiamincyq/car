# Neon Coast Rush 原创美术集成计划

本计划从已封存的本机版 `v0.2.0` 开始，在 `0.3.0-dev` 中逐层替换程序化占位视觉。美术不得改变碰撞框、道路宽度、状态时机、输入或存档。

| 阶段 | 预计用时 | 推荐模型/工具 | 交付物 | 状态 |
|---|---:|---|---|---|
| A0 风格与接口冻结 | 0.5 天 | Terra + Sol 复核 | 夜间海岸像素风、尺寸和配色语义 | 已完成 |
| A1 玩法主体精灵 | 1–1.5 天 | 图像模型 + Sol 集成 | 玩家车、轿车、厢式车、掀背车、跑车、货车、燃油 | 已完成；扁平问题已修复 |
| A2 道路与海岸环境 | 1.5–2 天 | 图像模型 + Terra | 可平铺路面、路肩、海岸侧景 | 已完成并通过试玩 |
| A3 HUD 与事件反馈 | 1–2 天 | 图像模型 + Terra | 面板、封路、检查点、结算装饰 | 已完成并通过试玩 |
| A4 动画与特效 | 2–3 天 | 图像模型 + Sol | 加速/制动、拾取、碰撞、通关动画 | 已完成并通过试玩 |
| A5 本机发布验证 | 1 天 | Sol 回归，Terra 打包 | 0.3.0 本机包、哈希、回滚记录 | 执行中 |

## A1 验收

- [x] 七张运行时 PNG 使用冻结画布和透明中心锚点。
- [x] 六种车辆使用不同轮廓，并按行为映射为轿车、厢式车、掀背车、跑车和货车。
- [x] 车辆使用近俯视投影和等比缩放，车身比例不再被压扁。
- [x] 交通类型继续通过非颜色符号区分。
- [x] 高分辨率源图不会进入 Windows 导出包。
- [x] 加速喷焰、碰撞摇摆/挤压和冲击环具有确定性边界测试。
- [ ] 玩家确认精灵在实际速度下清楚、方向正确、没有遮挡预警。

## A2 验收

- [x] 左侧岩岸植被与右侧海面浪花使用独立原创像素素材。
- [x] 上下镜像拼接，滚动循环边界无断缝。
- [x] 环境滚动独立于 92 像素车道虚线周期，不会发生短周期跳变。
- [x] 道路宽度、路肩、车道线、封路与碰撞几何保持不变。
- [x] 高对比模式会压低侧景亮度，避免削弱道路提示。
- [x] 玩家确认高速滚动时侧景不喧宾夺主、无明显重复感或眩晕感。

## A3 验收

- [x] HUD 外框保持原始比例，文字、燃油条和赛程条位于安全区内。
- [x] 燃油条、赛程条分别映射实时燃油百分比与终点距离百分比。
- [x] “即将封闭”使用斜向预警线，“已封闭”使用实体路障与黑色 X，状态不只依赖颜色。
- [x] 检查点、封路提示使用独立事件铭牌，结算界面使用原创完成徽章。
- [x] 44 项自动测试通过，离屏预览确认 HUD、事件板和实体路障无主要遮挡。
- [x] 玩家确认高速驾驶时 HUD 易读、封闭车道不可驶入、事件提示不会遮挡关键车辆。

## A4 验收

- [x] 加速使用双排气喷焰；制动使用双红尾灯与双轮拖痕，输入状态不只依赖颜色。
- [x] 燃油拾取使用扩散环与四向亮点，并保留原有拾取提示音。
- [x] 普通超车使用 3 条青色速度线；近失使用 6 条更粗的琥珀速度线与独立提示音。
- [x] 碰撞摇摆、挤压、冲击环、火花和可关闭屏幕震动保持正常。
- [x] 通关爆发和徽章入场不延迟 `RUN_CLEAR` 状态或结算按钮。
- [x] 瞬时特效具有硬对象上限和固定回收时间，关闭闪烁时不增加额外闪屏。
- [x] 玩家确认高速下制动、拾取、超车/近失和通关反馈清楚且不过度遮挡道路。

## A5 验收

- [ ] 项目、Windows 产品版本和标题页统一为 `0.3.0`。
- [ ] 全部自动测试通过，发布压力回归无断言失败。
- [ ] 全新用户目录可首启，候选 EXE 可正常退出且无残留进程。
- [ ] 导出包不包含 `tests/` 与 `art/source/`，EXE/ZIP 哈希已记录。
- [ ] `v0.2.0` 回滚路径和 `v0.3.0` 验收后打标签流程已记录。
- [ ] 玩家完成最终本机发布验收。
