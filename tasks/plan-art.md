# Neon Coast Rush 原创美术集成计划

本计划从已封存的本机版 `v0.2.0` 开始，在 `0.3.0-dev` 中逐层替换程序化占位视觉。美术不得改变碰撞框、道路宽度、状态时机、输入或存档。

| 阶段 | 预计用时 | 推荐模型/工具 | 交付物 | 状态 |
|---|---:|---|---|---|
| A0 风格与接口冻结 | 0.5 天 | Terra + Sol 复核 | 夜间海岸像素风、尺寸和配色语义 | 已完成 |
| A1 玩法主体精灵 | 1–1.5 天 | 图像模型 + Sol 集成 | 玩家车、普通车、货车、燃油 | 自动验收完成，等待试玩 |
| A2 道路与海岸环境 | 1.5–2 天 | 图像模型 + Terra | 可平铺路面、路肩、海岸侧景 | 待执行 |
| A3 HUD 与事件反馈 | 1–2 天 | 图像模型 + Terra | 面板、封路、检查点、结算装饰 | 待执行 |
| A4 动画与特效 | 2–3 天 | 图像模型 + Sol | 加速/制动、拾取、碰撞、通关动画 | 待执行 |
| A5 本机发布验证 | 1 天 | Sol 回归，Terra 打包 | 0.3.0 本机包、哈希、回滚记录 | 待执行 |

## A1 验收

- [x] 四张运行时 PNG 使用冻结画布和透明中心锚点。
- [x] 普通车与货车使用不同长宽轮廓，视觉尺寸对应既有碰撞边界。
- [x] 交通类型继续通过非颜色符号区分。
- [x] 高分辨率源图不会进入 Windows 导出包。
- [ ] 玩家确认精灵在实际速度下清楚、方向正确、没有遮挡预警。
