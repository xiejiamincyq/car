# 红车优先通行修复（2026-10-08）

用户本轮反馈替代RC3的“只由红车择空”策略：红车出现后其他机制为它让路，尽快通过被占据车道。

## 行为契约

1. 一个红车拥有优先通行权，从接受出生开始到自然退出视野结束；不同时生成第二红车。抵近玩家阶段短暂停止新增交通；通过玩家并拉开安全距离后，只在不冲突的其他车道恢复普通车生成，仍不允许挤占红车路线。结束/重开必须解除通行权。
2. 普通NPC不再规划进入优先通道；通道前方普通车在可见、预警充分、周边安全时主动变道让行。齐头双列通过有限减速错开；密集邻道还需要协调实际可并入的前后空隙。巡航值不改，瞬时速度依旧遵守140加速/420制动；不能长时间减慢红车自己的前车导致红车退场。正在转向的车仍连续完成，不能强制瞬移或取消成半车道状态，取消后的冷却也不能跳过。
3. 施工只暂缓新事件，既有可见施工继续与地面同步推进；不为了红车擦除/冻结障碍。冷却按真实游戏时间累计，已到期的新事件等优先通行结束再安排，不因每次红车出现而重新计时。红车有路线时避开既有施工，没有空间时必须有限制动。
4. 路线选择以安全预计通过耗时为准，优先直通或主动让出的通道，避免红车与普通车互相抢同一空道。玩家逃生、车体间距、金币/补给安全约束不放宽，不能以“最短”理由绕过它们。
5. 金币和补给不是实体障碍，不删除已生成道具；新生成的引导路线和补给避开优先通道。红车经过后恢复原有难度规则。
